    效率預算

    看 n 決定寫什麼複雜度

    判題機約每秒 108 次基本運算，時限通常 1–3 秒。讀完 n 的範圍就知道能不能暴力。

    最常見的誤判：n ≤ 5000 時 O(n²) 是 2500 萬次，可以過；n = 105 時 O(n²) 是 100 億次，必 TLE。 n 只差 20 倍，運算量差 400 倍。
